15号线大冒险 · 3D 小测试（第一章）
====================================
打开方式：直接双击 index.html（Chrome / Edge / Firefox / Safari 最新版，需要 WebGL2）。
不需要服务器，不需要联网，没有任何外部库——3D 渲染是自己写的 WebGL2。
点「开始 1-1」就进入第一章第一个房间；走到出口会自动进下一间，1-6 打完是结算页。

文件夹结构（和原版一样，只是只带了第一章用到的）
  index.html                 ← 游戏本体（渲染 + 玩法 + 界面，全在这一个文件里）
  js/data/defs.js            ← 原版：物件目录、颜色
  js/data/level-builder.js   ← 原版：关卡构建工具
  js/levels/c1-01 ~ c1-06.js ← 原版：第一章 6 个房间的数据（地形、敌人、对白完全没改）
  （你的音乐 mp3 放在和 index.html 同一层）

音乐
  index.html 开头的 CFG.music 是候选文件名，按顺序找，找到能播的就循环播放：
    music.mp3 → bgm.mp3 → Foothills 105.mp3 → Foothills.mp3 → OLD TITLE THEME 75.mp3 → assets/audio/Foothills 105.mp3
  想用别的文件名，改 CFG.music 即可。浏览器要求先点一下才能出声，所以有「开始」按钮。M 键静音。
  没找到音乐时左下角会提示，游戏照常玩（只有程序合成的音效）。

操作
  A D / ← →  移动      空格 / W / ↑  跳（空中再按一次二段跳）   K / Shift  冲刺
  J 教鞭    L 粉笔（远程）    E 互动 / 对话 / 翻页    ↓ + 跳  下穿薄地板
  Z X 或 鼠标拖动  转动视角     滚轮  拉近拉远     V  复位视角
  P / Esc 暂停    R 重开本房间    1~6  直接跳到 1-1 ~ 1-6    网址加 ?lv=4 可直接从 1-4 开始

这次 3D 化做了什么
  · 地形、背景、角色、敌人、机关全部用 3D 重新搭建：地块是有厚度的方块，雪松林、远山是真正有景深的 3D 物体，
    转动视角能看到视差；玩法仍然是「在一个平面上跑跳」的 2.5D（和原版同样的手感与数值）。
  · 原版的素材（贴图、角色图片）没有用，全部改成程序生成的低多边形模型；关卡数据、对白、碎片数量沿用原版。
  · 已实现：跑 / 跳 / 二段跳 / 冲刺 / 教鞭 / 粉笔 / 踩踏、碎片、保温杯、信标灯存档、尖刺、冰面打滑、薄地板、
    移动平台、碎裂平台、弹簧、风口、风区、冲刺水晶、冰锥、碎石、开关与闸门、史莱姆 / 飞行蜂 / 炮台、
    NPC 与路牌对话、触发区对话、1-6 的 Boss「风雪稽查员」（出口要打败它才开）。
  · 没做：藤蔓、成就 / 图鉴 / 存档、触屏按键、手柄，以及第二章以后的内容。

已知的粗糙之处（这是小测试）
  · Boss 的招式是我重新设计的简化版（走近 / 扔冰弹 / 跳砸），不是原版的行为。
  · 角色和怪物是简单几何体拼的，还没有细致的动画。
  · 我在无头浏览器里测过：6 个房间都能载入、不报错，移动 / 跳跃 / 攻击 / 尖刺 / 出口切关 / Boss 流程都跑通；
    但没有在真机上手感调试，也没有测手机。
