# 15号线大冒险 · 合并版（物理老师篇）

一名中学**物理老师**放学途中的奇遇：晚自习后，在 15 号线望京西站等末班车，站台尽头的楼梯通向风雪——想回家，只能一路往前，把沿途熄灭的信标重新点亮。

## 运行
直接双击 `index.html`（无需联网）。关卡工坊是 `editor.html`。
**资源文件没有包含在这里，请自己放回去：** `assets/zyj.png`（主角的脸）和 `assets/audio/` 里的 5 首音乐（见下）。缺音乐时自动用同 BPM 的合成音乐，缺头像时用默认脸，都不会报错。

## 这一版合并了什么
- **24 个房间**：4 章 × 6 关，每章最后一关是 Boss；第 4 章房间最短，结尾是守线者 Boss 战。
- **三个存档位**：开始新旅程 / 读取 / 覆盖 / 删除；暂停菜单里也能存档。
- **成就 · 晶体页**、**图鉴页**（记录见过的生物、NPC、障碍物、机关、道具）。
- **手感**：冰面和空中不再那么滑；新增**远程攻击——扔粉笔（L 键 / 触屏「粉笔」按钮）**，Boss 好打很多。
- **触屏布局三种**：分开（手机）/ 聚集（教室大屏）/ 隐藏（电脑），外加按钮大小，设置里切换。
- **物理老师设定**：所有 NPC 与剧情文本改成物理老师风格；地铁站名、线路名只在 `js/data/defs.js` 的 `STATION / LINE` 改一处。
- **新机关/生物**：旋转锯、冰锥、火焰、碎裂木板、传送带、冲刺晶、风口，青蛙、蝙蝠；黑板（物理公式）、横幅旗等装饰。
- **音乐连贯**：一整章只用同一首，换关不重播；Boss 房才切到 Boss 曲。
- **关卡一间一个文件**：`js/levels/c1-01.js … c4-06.js`，想删 / 换 / 加某一关，直接改 `index.html` 里的 script 列表即可。

## 关卡工坊
首次打开设一个密码（只存本机）。左侧改章节与剧情，中间画布放置物件 / 连线机关，右侧图鉴 / 属性 / 检查；「▶ 试玩本关」直接在游戏里试玩，「⬆ 发布到游戏」让游戏使用你编辑的主线，「⋯」里可恢复默认。草稿自动保存；用「导出全部」存成文件，换电脑再「导入」。

## 兼容性
纯 HTML/Canvas，不依赖外部网站或字体。支持 Chrome/Edge 61+、Safari 13+ 及 Chromium 内核的平板、教室一体机。存档在浏览器本地（localStorage），清除浏览器数据会清掉存档。
