======== 剧情与结构 ========
故事：末班车弄丢了自己的站名（线路图空白、广播只说“终点站：未知”）。老师一节一节往车头走，
把散落在车厢里的黄色水晶（=站名）找回来交给列车员，列车重新报站，平安到家。
第 1 章 载客车厢  窗外黄昏城市   座椅、碎玻璃、激光；介绍站名水晶
第 2 章 设备车厢  窗外夜色郊野   货箱、传送带、配电间（等离子体 / 电弧 / 磁场）
第 3 章 隧道区间  窗外隧道       结冰车厢、冰锥、低温陷阱、怨灵、幽灵
第 4 章 驶向车头  窗外黎明       重力井、异常体、幽灵、最终的车头
每章 3 关，每关 6 节车厢（300 格）。

======== 新增的 6 种车厢（js/data/metro-kit.js） ========
seat 座椅车厢：座椅是可站的砖块 + 飞蜂 / 探测球 / 幽灵
cargo 货运车厢：货箱砖块 + 装甲兵 / 跳跳蛙 / 碎石 / 火焰喷口
power 配电间：等离子体 + 电弧 + 电磁场 + 探测球 / 无人机
ice 结冰车厢：冰面 + 冰锥 + 低温陷阱 + 怨灵
ghost 幽灵车厢：幽灵 ×2 + 怨灵（高难度加异常体）
gravity 重力井车厢：重力井 + 异常体 + 哨兵
原有 plain / spikes / laser / belt / saw / mix 保留。

======== 说明 ========
1. 没有新增怪物 AI、新增地块编号或新贴图——怪物与机关全部复用游戏里已有的种类（飞蜂、跳跳蛙、
   探测球、怨灵、幽灵、异常体、等离子体、低温陷阱、电磁场、重力井、火焰喷口、冰锥、碎石），
   在地铁里重新混搭。这样不用改 game.js / dlc-engine.js 的核心逻辑。要做真正全新的怪物或
   方块（新行为、新贴图），需要再改 dlc-engine.js / gfx4.js / defs.js，可以下一步再做。
2. 旧版地铁历险里已经收集的黄色水晶不会计入新版（水晶 ID 改成了 m11-1 这类按关编号，
   避免和别的 DLC 的存档记录冲突）。想清掉旧的地铁历险存档：浏览器里删除 localStorage 的
   line15-dlc-save-subway_adventure 即可。
3. 如果你在关卡工坊里发布过地铁历险，浏览器里那份会覆盖源码：先在工坊 → DLC管理 里恢复默认，
   或清除 localStorage 里的 line15-dlc-campaign-subway_adventure，否则看不到新内容。
4. 已在完整项目副本里运行 node tools/validate.js：12 个地铁关卡全部通过（0 错误 0 提示）。
   validate 仍报告主线第 5 章（5-1、5-2）的 4 个错误，那是你自己在做的新章节，和本次改动无关。
5. 未在真机或浏览器里实际试玩，请先在电脑上通关试一遍再放给学生。
6. 想自己重新生成 changelog-data.js：在游戏根目录运行  node tools/build-changelog.js
